# AGP Signed Decision Context 1.0 — Design Stage

This package adds the first design draft for the Signed Decision Context security
architecture.

Apply from the repository root:

```bash
unzip -o ~/Downloads/agp-signed-decision-context-1.0-design-stage0.zip -d .
```

Then review:

```bash
sed -n '1,260p' spec/AGP-SIGNED-DECISION-CONTEXT-1.0-DESIGN.md
sed -n '261,620p' spec/AGP-SIGNED-DECISION-CONTEXT-1.0-DESIGN.md
git status --short
```

Do not activate the Schema Registry entry yet.
